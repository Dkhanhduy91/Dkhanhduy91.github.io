Privacy policy

Last updated: 30 October 2026

Hermes is a personal assistant used only by its owner, Khanh Duy. This policy explains how it handles Google user data.

What data Hermes accesses

Hermes only accesses the Google account data its owner grants it through Google sign-in, such as email, calendar or files, and only for the scopes shown on the consent screen.

How the data is used

The data is used only to help the owner manage his own notes, email and calendar. It is not sold, shared with third parties, or used for advertising.

Storage and security

Data is processed on the owner's private server and laptop. Access tokens are stored on that server and are never published.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Hermes's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
